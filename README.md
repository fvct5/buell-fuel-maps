# Buell Fuel Maps

This is a collection of Buell EEPROM's for use with EcmSpy software, which can be found at the [EcmSpy Website](https://www.ecmspy.com/downloads.shtml).

The files were gathered from the community of Buell riders, and some might not even work or could be corrupted. It is recommended that you only expiriment with the fuel maps from these files. Burning the whole EEPROM could brick your ECM. Please use these files **AT YOUR OWN RISK!!!** I am not responsible for any damage to your bike.

If you have any questions, go to the [BuellXB Forums](https://www.buellxb.com/) and search around for your answers.
